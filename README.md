# Beauty Clinic Landing

repo นี้มีไฟล์เดียวคือ Beauty clinic landing page.zip ข้างในเป็นแลนดิ้งเพจคลินิกเสริมความงามภาษาไทยแบบหน้าเดียว (ตัวอย่างชื่อ ลมิรา คลินิก) พร้อมวิดีโอ hero และรูปประกอบ แตกไฟล์ zip แล้วเปิด beauty-clinic.dc.html ในเบราว์เซอร์ได้ทันที หรือเสิร์ฟด้วย python3 -m http.server 8000 ชื่อคลินิก ที่อยู่ เบอร์โทร และรีวิวในหน้าเป็นข้อมูลตัวอย่าง ต้องแทนด้วยข้อมูลจริงก่อนเผยแพร่
